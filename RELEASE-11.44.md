# 11.44 — свежая подборка и исключение обработанных карточек

- По умолчанию: сегодня, сначала свежие, непросмотренные и без одновременного наличия аватара и обложки. Фильтр оформления оценивает наличие элементов, не художественное качество. Его можно отключить.
- Статусы «Диалог открыт», «Предложение отправлено», «Ответили», «Клиент» исключены из поиска даже после сброса фильтра и очередного серверного обновления. Они доступны в «В работе» без ограничения сегодняшним днём. Добавлена ручная отметка «Уже написал» для прежних обращений вне приложения.
- Исправлена гонка между автообновлением и открытой карточкой: статус сохраняется у текущей записи по ID, а не только у устаревшего объекта модального окна. Запрос открытия диалога не означает подтверждённую отправку.
- Сборщик тратит повторные проверки на интервалы последних 24 часов. В каждом часовом сегменте первыми проверяются кандидаты без полного оформления; квоты час / 1–3 часа / сегодня сохранены. Старая история не получает новую дату.
- Поддержаны owner_id и to_id при проверке владельца публикации. Непустая стена без распознанных дат не считается успешно проверенной. Старые оригинальные публикации исключают кандидата; вложенные даты репостов не используются.
- Пустой период в поиске ограничен последними 24 часами. Личные статусы учитываются в счётчиках кнопок. Рейтинг больше не награждает наличие полного оформления.
- Обновление различает новый серверный снимок и повторное получение прежнего. Автообновление клиента раз в минуту не выдаётся за новый скан VK. GitHub Actions работает по расписанию с возможными задержками.

Проверка: 131 автоматический тест пройден. Покрыты сохранение статуса при замене объекта ленты, исключение обработанных после слияния, фильтр оформления, граница 24 часов, приоритет неполного оформления, to_id и непроверенная стена.

Ограничения: история обработки хранится в браузере, сообщения вне приложения автоматически не читаются. Официальная дата создания сообществ не получена: показываются кандидаты по переходам ID с проверкой доступности и стены. Возраст регистрации и охват всех сообществ VK не гарантируются.
