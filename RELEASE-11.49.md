# VK Leads 11.49 — качество подбора

- Окно проверки: 18 000 ID вместо 12 000; до 1 000 проверок кандидатов вместо 800 за цикл. Паузы API и расписание не ускорялись.
- Сохранение до 20 000 недавних записей с приоритетом подходящих сообществ. Очередь повторной проверки временных названий: до 1 500 вместо 500; неудачные проверки больше не занимают первые места бесконечно.
- Расширены ниши: ателье, груминг, перевозки, реставрация, перетяжка, бурение, флористика, детейлинг, английские названия beauty/nails и другие услуги.
- Единый фильтр порнографии для сервера и клиента: название, описание, категория; сервер дополнительно проверяет тексты пяти последних и пяти первых постов, доступные подписи вложений и репосты. Исходные тексты постов не сохраняются в ленту.
- Блокировка известного порноконтента действует и для ранее сохранённых карточек. Безопасность самих изображений/видео не классифицируется: текстовый фильтр не гарантирует выявление контента без текстовых признаков.
- Уточнены ложные совпадения в медицинских темах; музыкальные школы и груминг не отбрасываются как хобби. Убраны шаблонные приманки «твой подарок ждёт».
- Переписка и кнопки навигации не менялись.

Достоверность: интервал появления по росту ID не равен подтверждённой дате регистрации VK. Старые обнаруженные посты, недоступные страницы и повторяющиеся ID исключаются. Расписание GitHub Actions может задерживаться; все сообщества VK и фиксированное количество лидов не гарантируются.

Проверка до релиза: снимок реальной публичной ленты из 897 карточек; фильтр выявил 203 карточки по взрослому контенту. Это сравнение одного снимка, а не измерение прироста новых сообществ. Фактический объём зависит от новых данных VK.
