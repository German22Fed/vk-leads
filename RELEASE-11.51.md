# VK Leads 11.51

Дополнение 11.51.1: до получения актуального серверного снимка раздел новых сообществ пуст; сохранённые ранее ID не допускаются в него без присутствия в текущем снимке. Личная история остаётся в отдельном разделе. Пример пользователя 242923551 не найден в проверенных выгрузках 11.49–11.51; защита проверена регрессионным тестом с этим ID. Удалены дополнительные ложные коммерческие совпадения (личные свадебные альбомы, общее «Красота и здоровье», обсуждения для психологов). Итоговая проверка — 163 теста.

Подбор стал строже к новизне и шире по коммерческим нишам.

- Периоды «час» и «1–3 часа» принимают только интервалы наблюдения, целиком попадающие в выбранные границы. Раньше достаточно было времени первого появления в конце интервала: группа с неопределённостью более часа могла попасть в последний час.
- Сборщик запрашивает crop_photo и исключает кандидата, если принадлежащая самому сообществу фотография старше интервала появления. Старые собственные фотографии во вложениях тоже учитываются. Даты чужих фотографий и источников репоста не принимаются за возраст сообщества. Исторические сведения сохраняются при смене фотографии.
- Стена с неполной/изменившейся последней страницей не считается проверенной. Следующая проверка повторяет запрос. Версия проверки заставляет обновить прежние карточки.
- По умолчанию включён фильтр «Стартующие проекты»: до 10 постов и 150 подписчиков. Его можно отключить; сохранённые карточки не теряются. Это эвристика пригодности, а не доказательство регистрации. Фильтр готового оформления сохранён.
- Добавлены ресничные мастера и варианты написания, ногтевые услуги, колористика, изделия на заказ, бытовой ремонт, строительство, пищевые товары, профессиональные услуги. Исправлен отсев магазинов игрушек/книг, нейропсихологов, груминга и частных детсадов. Имя/бренд без ниши допускается только при конкретной услуге и коммерческом предложении в описании; «Мама», площадки, случайные названия и порноконтент не допускаются.
- Помимо 24 000 последовательных ID проверяются три блока впереди до +96 000 (297 дополнительных ID). Найденная более высокая граница используется для следующих наблюдений; найденные впервые существующие группы не выдаются за новые.
- Расписание перенесено на минуты 7/17/27/37/47/57. GitHub не гарантирует запуск по времени: https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows#schedule
- В одном запуске выполняются два последовательных прохода с сохранением состояния между ними. Второй повторно использует свежие проверки стен и устанавливает более узкий интервал для групп, появившихся во время первого прохода. Это не обеспечивает непрерывного наблюдения между запусками GitHub.

Источник поля crop_photo: https://github.com/VKCOM/vk-api-schema/blob/master/groups/objects.json

Проверки: 162 автоматических теста, включая старые фото, неполную стену, границы периода, новые бизнес-ниши и продвижение вперёд без выдуманной даты создания. Реальная регистрация VK по этим признакам не подтверждается; отсутствие старых материалов не доказывает, что группа создана недавно. Проверка данных не гарантирует исключения всех восстановленных/очищенных сообществ.
