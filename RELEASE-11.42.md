# 11.42 — охват и справедливая очередь проверки

Проблема: количество опубликованных карточек ошибочно воспринималось как число новых групп VK. Снимок предыдущего состояния содержал 1904 кандидата, включая 85 с верхней границей интервала за 1–3 часа, но 1331 кандидат имел устаревшую проверку стены, ещё 123 не были проверены. Эти категории не являются независимыми доказательствами даты создания.

Изменения:

- 6000 последовательных ID за проход вместо 2000. Это ограниченный диапазон у оценённой верхней границы, не полный обход VK.
- До 400 проверок кандидатов за проход. Квоты между последним часом, 1–3 часами, сегодняшним днём и более старой историей; свободная квота перераспределяется.
- Успешные проверки повторяются после 40 минут вместо 10. Для публикации по-прежнему необходима проверка не старше часа.
- Снято ограничение выдачи в 500 карточек. История ограничена 10000 кандидатами; число удалённых из-за лимита показывается отдельно.
- Переход ID фиксируется до тематического фильтра. Временное название проверяется повторно в течение суток, даже после ухода ID за границу сканирования. Исходный интервал никогда не сбрасывается при переименовании.
- После длительной паузы допускается широкий интервал наблюдения до суток. Он не попадает в часовой фильтр, если полностью не помещается в него.
- В интерфейсе добавлены охват ID, пауза между проходами, причины отсева, очередь и число карточек, пересекающих границу периода.

Проверка: 119 тестов; новые случаи — всплеск часовых кандидатов не вытесняет 1–3 часа, диапазон >2000, переименование после продвижения окна, 700 карточек без обрезки, неопределённость границ периода.

Гарантии и ограничения: эти данные не содержат официального времени регистрации. Скрытые/восстановленные группы полностью исключить нельзя. Старые посты служат отрицательным признаком; отсутствие старых постов не доказывает новизну. Уже пропущенные интервалы прошлых запусков восстановить задним числом нельзя. GitHub Actions может задерживать расписание; обещать полный постоянный охват всех новых групп или фиксированное количество лидов нельзя.
